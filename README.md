# Portafolio Profesional Web

¡Bienvenido/a a mi portafolio profesional! Este proyecto es una página web responsive diseñada con la filosofía **Mobile First**, utilizando las tecnologías web fundamentales y el framework **Bootstrap 5**.

---

## Tecnologías Utilizadas

- **HTML5**: Estructuración semántica de la página.
- **CSS3 / Flexbox**: Estilos personalizados y alineación flexible.
- **JavaScript**: Interactividad en la aplicación web.
- **Bootstrap 5**: Sistema de grillas responsive, Cards, Progress Bars/Badges y componentes UI.

---

## Características del Proyecto

- **Hero Section**: Presentación personal con foto, rol y botones de acción.
- **Portafolio de Proyectos**: Visualización de proyectos (POS / CRUDs) adaptable a móviles y escritorio.
- **Habilidades Técnicas**: Nivel de dominio en PHP, MySQL, JavaScript, HTML y CSS mediante componentes visuales de Bootstrap.
- **Currículum Vitae**: Enlace directo para visualización y descarga del CV en formato PDF.
- **Contacto y Redes**: Enlaces directos a redes profesionales y correo de contacto.
